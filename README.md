# 越南協發有限公司财务管理 · 电脑/手机/网页一体版

同一套代码，GitHub 云端自动打包，产出三种使用方式：

| 产物 | 适用设备 | 获取方式 |
|---|---|---|
| 越南協發有限公司财务管理-电脑版.exe | Windows 电脑 | Actions 工件，双击即用免安装 |
| 越南協發有限公司财务管理-手机版.apk | 安卓手机 | Actions 工件，点击安装 |
| 网页版（PWA） | 苹果/安卓/电脑浏览器 | GitHub Pages，添加到主屏幕 |

## 一、注册并登录 GitHub（已有账号跳过）

1. 打开 https://github.com/signup ，用邮箱注册，验证邮箱后登录。
2. 免费账号即可，云端打包完全免费。

## 二、新建仓库并上传代码

1. 右上角 ＋ → New repository，仓库名填 `ar-management`，选 Private（私有），不要勾选初始化文件，点 Create。
2. 在空仓库页面点 **uploading an existing file**，把本压缩包解压后的**全部文件和文件夹**拖进去（含 .github 文件夹；若看不到 .github，资源管理器“查看”里勾选“隐藏的项目”）。
3. 页面底部点 **Commit changes**。

## 三、开启网页版（PWA）

1. 仓库 Settings → Pages → Source 选 **GitHub Actions**。
2. 打包流程会自动部署，约 1–2 分钟后 Pages 页显示网址。
3. 手机用浏览器打开该网址：
   - 安卓 Chrome / 苹果 Safari：菜单里选“添加到主屏幕”，桌面出现图标，打开即全屏 APP，离线可用。

## 四、下载 exe 和 APK

1. 仓库顶部 **Actions** 标签，点最新一次运行记录。
2. 页面底部 Artifacts 里有「电脑版-exe」「手机版-apk」，点击下载（需网页登录 GitHub）。
3. 电脑：解压后双击 exe，若弹 SmartScreen，点“更多信息 → 仍要运行”。
4. 安卓：把 apk 发到手机，点击安装，提示“未知来源”时允许即可。

## 五、后续更新代码

每次重新上传文件并 Commit，Actions 会自动重新打包、Pages 自动更新。
想要正式版本号下载：在仓库 Releases → Draft a new release → 填写 tag（如 v1.0）→ Publish，exe 和 apk 会自动挂到 Releases。

## v5.4 更新内容

- 新增「收款」页：按手动填写的收款日期统计每月实际回款（笔数、客户数、VND/USD 金额、手续费），点月份可看当月逐笔明细，并可导出 Excel。
- 「＋ 登记收款」入口：选客户（可指定某张发票），手动填写收款金额和收款日期。
- 收款明细支持「改日期」；导入 Excel 时自动登记的已收款默认不计入（日期是导入当天），补填真实日期后计入。
- 「清款」「客户清款」新增收款日期输入，不再固定记为当天。
- 合并时修正快捷清款的手续费分配记录，撤销该笔收款时可正确还原手续费。

## v5.3 更新内容

- 总览「月度汇总」的操作按钮列、对账单预览的「状态/标记」列冻结在右侧，横向滑动时始终可见。

## v5.2 更新内容

- 利润口径修正为：当月发票总金额（含税，USD 按当前汇率折算）− 当月支出总金额。
- 利润不再按实际收款计算；未收货款单独显示，不影响利润。
- 总览、支出/利润页、KPI 与全部 Excel 利润导出口径保持一致。

## v5.1 更新内容

- 新增「支出/利润」页面：每月填写一次支出总金额（VND），可随时修改或清除，三端云同步。
- 自动计算每月利润：当月实际收入（含现金，USD 按当前汇率折算）− 当月支出总金额；银行手续费不重复扣除。
- 总览看板与月度汇总新增支出、利润列，支持一键跳转填写对应月份支出。
- 新增月度利润表 Excel 导出；JSON 备份与恢复现包含月度支出，兼容旧版备份。

## v5.0 更新内容

- 浅色商务界面：白色侧边栏、卡片化看板、柔和阴影，手机端自适应布局。
- 全局搜索：按客户、代码、发票号、税号、地址模糊查询（支持越南语声调忽略）。
- 组合筛选：收款状态（未收/部分/已清款/现金）、币种（VND/USD）、月份区间。
- 列表排序：客户与发票明细支持按客户、金额、未收余额、日期、发票号等列排序。
- 同步状态徽章：顶栏实时显示 已同步 / 同步中 / 离线缓存 / 连接中 / 出错 及最后同步时间。
- 保留原有功能：Firebase 三端实时同步、公司 LOGO、账号登录、删除密码保护、离线可用、Excel 导入导出与备份恢复。

## 数据安全提醒

- 数据保存在 Firebase 云端，登录后电脑、手机、网页三端实时同步；本机同时保留离线缓存。
- 仍建议定期用软件内「管理 → 导出备份」保存 JSON，换设备或异常时用「恢复备份」迁移。
